What tokens can and cannot do

{{template "icon" "shield"}}
  • A token is a secret, like a password. Anyone who holds it can act as you within its scope, from any machine.
  • Tokens work for git over HTTPS and MCP only. They cannot sign in to this website or create other tokens.
  • A read token can clone and read. A write token can also push, and open and change issues and merge requests.
  • NewGit stores only a hash, so a lost token cannot be shown again. Revoke it and create a new one.
  • Your device key never leaves this browser. If you clear this site's data, the key is gone and you lose access to this account. Revoke tokens first if you want them to stop working.
